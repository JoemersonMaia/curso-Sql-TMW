# 🗄️ Curso Completo de SQL

Curso **completo e gratuito de SQL**, ministrado por **Téo Me Why**, voltado para quem deseja aprender SQL desde os primeiros conceitos até conteúdos mais avançados.

SQL é uma das principais linguagens utilizadas na área de dados e permite consultar, transformar e analisar informações armazenadas em bancos de dados relacionais.

A ideia principal deste curso é fornecer uma base sólida sobre **SQL e bancos de dados relacionais**, passando pela sintaxe da linguagem, consultas, filtros, agregações, cruzamento de dados, subqueries, CTEs e funções de janela.

## 🎯 Objetivo

Ao final deste curso, você terá uma base sólida em:

* Conceitos de bancos de dados relacionais
* Sintaxe SQL
* Consultas com `SELECT`
* Filtros com `WHERE`
* Criação de novas colunas
* Ordenação de dados
* Estruturas condicionais com `CASE WHEN`
* Funções de agregação e estatísticas
* `GROUP BY` e `HAVING`
* `DISTINCT` e `COUNT`
* Cruzamento de dados
* `JOINs`
* Subqueries
* CTEs
* Enumeração de linhas
* Window Functions
* Conceitos de DDL e DML
